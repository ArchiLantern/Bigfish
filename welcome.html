需要一个 API Key

就像给 AI 充点「话费」
学生用量很低，充 10 块能用很久
  1. 去 DeepSeek 官网注册/登录
  2. 在「API Keys」页面创建一个 Key并复制
  3. 新用户通常有免费额度，不够再充值
按钮会在浏览器打开 DeepSeek 官网

✅

把 Key 填进软件

为了你的 Key 安全，我们不收集它
请把它填进软件自带的设置里
  1. 点击下方「开始使用」进入主界面
  2. 打开软件右上角/侧边栏的「设置」
  3. 找到「模型 / API Key」，把 Key 粘贴进去并保存
